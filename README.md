# yulisha202411998302
**人海中寻找真爱 —— 信号检测论（SDT）实验**
工程心理学 · 作业一：用来演示信号检测论中的辨别力（d′） 与 判断标准（c）。

**运行方式**
直接用浏览器打开 index.html 即可（无需服务器、无任何外部依赖）。
建议 Chrome / Edge 全屏运行，屏幕亮度适中。

**实验任务**
屏幕中央先出现注视点「+」，随后闪现一屏人群（3 × 3 = 9 人），人群中可能藏着一位「真爱」。
被试需要在刺激消失后判断：刚才的人群里出现真爱了吗？（按 F = 有真爱，J = 没有）
所有人形、灰色、大小完全相同，唯一的区分特征只有胸口的心形完整程度，共有三种状态：
完整的心（100%）代表真爱（信号 S），每屏最多 1 个；3/4 颗心（75%）是干扰项（高相似度），右侧约 1/4 被裁掉；半颗心（50%）是干扰项（噪声 N），右侧一半被裁掉。刺激仅靠形状区分（不使用亮度、颜色、闪光等会引发 pop-out 的线索），避免平行搜索让任务变得过于容易。

**实验参数**
试次总数：24（满足「≥ 20 试次」要求，信号/噪声各 12 次，随机平衡序列）
先验概率：P(S) = P(N) = 0.5
每屏人数：9 人（3 列 × 3 行，带随机抖动，避免规则矩阵便于扫描）
干扰项构成：每屏 4 人为 3/4 颗心、其余为半颗心（有信号时含 1 位真爱）
心形比例：心宽约 32px，约为人身高（180px）的 18%，位于胸口
呈现时长（难度）：容易 1.5s / 中等 1.0s / 困难 0.5s
注视点间隔：400 ms
反馈：全程无即时反馈；作答后直接回到注视点，全部结束后统一报告结果
刺激消失后立即以杂乱灰点掩蔽，防止被试回视刺激；作答时记录反应时（RT）。

**统计指标与公式**
使用对数线性校正（log-linear correction）避免极端比例（0 或 1）导致 z 值无穷大：
P(Hit) = (hit + 0.5) / (nS + 1)
P(FA)  = (fa  + 0.5) / (nN + 1)
d′ = z(Hit) − z(FA)               辨别力（越大越能区分真爱与干扰）
c  = −[z(Hit) + z(FA)] / 2        判断标准（>0 偏保守，<0 偏宽松，=0 中性）
β  = exp( [z(FA)² − z(Hit)²] / 2 )  似然比
关于 c 的解读（常见疑问）
当信号与噪声试次数量相等（本实验各 12 次）时，c 完全由「回答有」的总比例决定：
- 回答「有真爱」恰好 12 次（占 50%）→ c = 0，β = 1
- 多于 12 次 → c < 0（偏宽松，倾向说有）
- 少于 12 次 → c > 0（偏保守，倾向说没有）
因此 c = 0 不是计算错误，而是「零偏向」的中性标准；在 P(S) = 0.5 时它也正是不偏不倚的最优策略。
c 反映反应偏向，与辨别力无关——辨别力要看 d′。

**实验结束后的输出**
1. 四类结果计数与概率：击中 Hit、漏报 Miss、虚报 FA、正确拒绝 CR
2. 指标卡：d′、c、β、回答「有真爱」的比例、总体正确率
3. 文字解读：根据 d′ 与 c 给出个性化说明
4. 逐试次记录表（实际信号 / 被试判断 / 结果 / 反应时）
5. 可视化
  - 交互式双分布图：拖动 d′ 与 c 滑块，实时观察击中区与虚报区面积变化，可一键载入自己的实测结果
  - ROC 曲线：等敏感度曲线族 + 标注被试的实测操作点
